# Felipe Dutra 👩🏻‍💻

**`Engenheiro de Dados`**

Profissional da área de Engenharia de Dados, focado no desenvolvimento de pipelines robustos, criação de processos ETL escaláveis e implementação de soluções eficientes para grandes volumes de dados. Experiência no uso de tecnologias como Python, SQL, MySQL, Databricks, Apache Spark, Git e Docker. Comprometido com boas práticas de engenharia, desempenho otimizado e entrega de valor por meio de dados bem estruturados. Atualmente em constante aprimoramento nas áreas de big data, armazenamento em nuvem e integração de dados distribuídos.
